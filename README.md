# Scout
A roblox lookup tool when youre too lazy to just go to the website, Better to never use this.


small roblox user lookup tool. type a username and it shows their join date, account age, friends, followers, and an estimate of their avatar’s value.

a little help from claude ( i made the background and everything else, thanks claude for helping me get the search player to work
used only with python, the info is taken from roblox's public api
